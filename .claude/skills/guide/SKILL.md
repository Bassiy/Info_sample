スキル一覧を動的に生成する。事前に書かれた固定リストは使わず、毎回ファイルシステムから読み取る。

## 手順

1. 現在のプロジェクトのスキルディレクトリ一覧を取得する

   ```bash
   ls .claude/skills/
   ```

   `.claude/skills/` が存在しない場合は「このプロジェクトにはスキルがありません」と表示して終了する。

2. 各ディレクトリの `SKILL.md` を読み込み、frontmatter の `name` と `description` の1〜2行目を抽出する

3. 以下のフォーマットで一覧を表示する

   | スキル | できること | 主な使いどき |
   |--------|-----------|-------------|
   | `/name` | 概要1行 | 典型的な呼び出し例 |

   - `name` はfrontmatterから取得
   - 「できること」はdescriptionの最初の文（何をするか）
   - 「主な使いどき」はdescriptionから使いどきのフレーズを1〜2個ピックアップ

4. 一覧の後に補足情報を動的に生成して表示する

   - `.claude/CLAUDE.md` が存在する場合はそれを読み込み、プロジェクトの目的・フォルダ構成・運用ルールなど、ユーザーが把握しておくべき情報を**要約して**表示する
   - `.claude/CLAUDE.md` が存在しない場合は補足セクション自体を省略する
